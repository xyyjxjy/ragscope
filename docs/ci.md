# CI 管什么

`.github/workflows/ci.yml`，每次 push 自动跑，全离线不烧 token。

| 作业 | 检查 | 挡住的典型事故 |
|---|---|---|
| test × py3.10/3.12/3.13 | 80 条单测 + 语法检查 | 只在本机 3.13 跑得通 |
| test | mock 闭环（判定数>0、变体>0、`is_mock` 为真） | 改动把闭环打断 |
| guards | 扫 `sk-` 形态串 | **密钥进仓库**（真发生过一次） |
| guards | HarmBench 派生数据不得入库 | 违反其再分发条款 |
| guards | 用例里的判定器必须已注册 | 改判定器名后用例静默失效 |

guard 的 `sk-` 扫描针对**当前树**；历史 commit 里若残留已吊销的旧 key，属已知情况（该 key 已在服务端销毁，字符串无效）。
